## About

我對控制系統有著濃厚的興趣，透過參加多場技能競賽的經驗，累積了機電整合與工業自動化的實作經驗。

在全國高中工業類技藝競賽中，我於機電整合職類獲得第一名。這項競賽要求在有限時間內從零建置一套完整系統，涵蓋 PLC 程式撰寫、機構組裝、感測器整合以及設備調校。我在團隊中主要負責程式撰寫，也因此累積了扎實的邏輯分析與現場排除問題的能力。

除此之外，我也參與過多項機器人與智慧製造相關競賽，逐步培養出跨領域整合的能力。

我也曾赴德國進行工業領域海外研習，實地接觸了當地的職業教育，同時參訪多家國際大廠，讓我對工業自動化與智慧製造有更深一層的體會。

進入大學就讀後，我開始意識到，技能競賽的訓練多聚焦於實作操作與現場整合，較缺乏進一步深入所需的理論基礎與系統性分析方法。有了競賽的實作經驗，反而讓我更清楚，沒有理論支撐的操作技巧，就無法進入到研究的深度。也因此我更明確地看見，若要在機器人與自動控制領域走向研究層次，就得主動補強數學、控制理論與系統建模這些基礎知識。
